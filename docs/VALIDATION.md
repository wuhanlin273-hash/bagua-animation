# 发布包验证记录

验证日期：2026-10-21（北京时间）

## 验证环境

- Windows；Chrome 155.0.8059.85；1600 × 900 视口。
- 使用 Playwright 驱动独立浏览器，通过仅监听本机的 HTTP 静态预览服务测试。
- 未安装项目运行依赖；未连接账号或外部服务。
- 自动化浏览器工具限制访问 `file:` 地址，因此本轮没有直接验证双击文件的启动路径。核心页面仅引用同目录 CSS/JS，绘图素材在浏览器内生成；双击运行方式基于这一自包含结构提供。
