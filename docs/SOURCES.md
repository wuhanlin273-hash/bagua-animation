# 来源与开发说明

## 视觉参考

原项目以已有的八卦动画截图和视频作为视觉练习参考，用于观察图层排布和运动效果。现存记录未完整保留这些参考素材的原作者、原始链接和授权信息，因此暂时无法提供完整的来源归属。

本发布包不分发这些参考截图或视频，也不宣称罗盘整体视觉设计完全原创。`preview.png` 是本包运行结果的截图；如提供其他演示素材，它们也应来自本包实际运行。

## 实现方式

项目由 GitHub 用户 [wuhanlin273-hash](https://github.com/wuhanlin273-hash) 通过 Codex 多次迭代开发，采用 AI-assisted implementation：由用户提出目标、观察效果和反馈，借助 Codex 完成代码实现及调整。这里不将代码描述为全部独立手工编写。

运行入口为 `index.html`、`style.css` 和 `script.js`。图形通过 SVG 绘制，页面样式和动画由 CSS、JavaScript 实现；字体取自用户系统，未随包附带字体文件。
